# Assigment1-Matrix-Multiplication
## Overview.
This project compares the performance of basic dense matrix multiplication implemented in Python, Java and C.

The objective is to study how execution time and memory usage change as matrix size increases.

## Project Structure.
- python/: Python implementation.
- java/: Java implementation.
- c/: C implementation.
- run_experiment.py: experiment runner.
- requirements.txt: Python dependencies.
- REPORT_TEMPLATE.md: report template.
- results/: experimental results generated when the experiment is executed.

## Requirements.
- Python 3
- Java Development Kit (JDK)
- A C compiler
- Python packages listed in requirements.txt

Instructions for compiling and executing the implementations, as well as running the complete experiment, will be added once the environment has been tested.
